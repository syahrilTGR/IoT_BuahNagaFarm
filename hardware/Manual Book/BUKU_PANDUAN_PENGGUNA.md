## BAGIAN 1: MENGENAL ALAT SMARTNAGA

### 1.1 Apa Fungsi Alat Ini untuk Kebun Anda?

Sebagai petani buah naga, Anda tentu menyinari kebun pada malam hari (biasanya selama 4–6 jam) untuk merangsang bunga keluar di luar musim (*off-season*). 

**Alat SmartNaga hadir untuk membantu pekerjaan Anda sehari-hari:**
1. **Tidak Perlu Bolak-balik ke Kebun Malam-Malam:** Anda bisa menyalakan atau mematikan lampu kebun langsung dari tempat tidur lewat HP, atau memasang jadwal otomatis.
2. **Tahu Berapa Lampu yang Putus:** Jika ada beberapa bohlam yang putus atau lepas, alat ini langsung memberi tahu Anda di layar dan di HP (misal: *"2 lampu mati"*).
3. **Pemberitahuan Listrik PLN Padam:** Jika listrik PLN di kebun padam mendadak, alat akan membunyikan alarm keras dan mengirim pesan darurat ke HP Anda saat itu juga.
4. **Pantau Biaya Listrik:** Anda bisa melihat pemakaian listrik kebun secara nyata (dalam Watt dan kWh) sehingga biaya listrik bulanan bisa diperkirakan.

---

### 1.2 Mengenal Bagian Luar & Dalam Box Panel

Alat SmartNaga diletakkan di dalam kotak panel pelindung putih/abu-abu tahan cuaca. Berikut bagian-bagian yang perlu Anda ketahui:

```
┌───────────────────────────────────────────────────────────────┐
│                      BOX PANEL SMARTNAGA                      │
│                                                               │
│   ┌──────────────────────────┐    ┌──────────────────────┐    │
│   │   LAYAR MONITOR KECIL    │    │  SAKLAR UTAMA (MCB)  │    │
│   │  (Menampilkan Jam, WiFi, │    │  [  ON  ]  [  ON  ]  │    │
│   │   Daya, & Status Lampu)  │    │  (PLN)     (Lampu)   │    │
│   └──────────────────────────┘    └──────────────────────┘    │
│                                                               │
│   ┌──────────────────────────┐    ┌──────────────────────┐    │
│   │  LUBANG KABEL KE KEBUN   │    │  BATERAI CADANGAN    │    │
│   │  (Kabel Lampu Blok A     │    │  (UPS agar alat      │    │
│   │   dan Lampu Blok B)      │    │   tetap hidup)       │    │
│   └──────────────────────────┘    └──────────────────────┘    │
└───────────────────────────────────────────────────────────────┘
```

1. **Layar Monitor Kecil (OLED):** Menampilkan jam kebun, status koneksi internet, berapa watt listrik yang terpakai, dan apakah kondisi lampu sehat atau rusak.
2. **Saklar Pengaman (MCB):** Tuas pengaman listrik. Posisi ke **ATAS = HIDUP (ON)**, posisi ke **BAWAH = MATI (OFF)**.
3. **Baterai Cadangan (UPS):** Menjaga agar alat pemantau dan modem internet tetap hidup meskipun listrik PLN di kebun padam.
4. **Lubang Kabel Bawah:** Tempat keluarnya kabel menuju lampu kebun Blok A dan Blok B.

---

### 1.3 Pembagian Dua Blok Lampu (Blok A & Blok B)

Untuk memudahkan pengelolaan dan menghindari beban listrik melonjak sekaligus, lampu kebun Anda dibagi menjadi dua kelompok:
* **Blok A:** Barisan tiang/pohon buah naga bagian pertama (misal: sisi Barat / Blok depan).
* **Blok B:** Barisan tiang/pohon buah naga bagian kedua (misal: sisi Timur / Blok belakang).

Anda bisa menyalakan Blok A saja, Blok B saja, atau keduanya secara bersamaan.

## BAGIAN 2: CARA MENYALAKAN ALAT PERTAMA KALI

### 2.1 Menghidupkan Daya Listrik (MCB & UPS)

1. Pastikan steker kabel daya kontrol sudah tercolok ke stopkontak baterai cadangan (UPS).
2. Naikkan tuas **MCB Utama PLN** ke atas (posisi **ON**).
3. Naikkan tuas **MCB Lampu Beban** ke atas (posisi **ON**).

---

### 2.2 Tanda Alat Sudah Siap Bekerja

Setelah listrik dinyalakan:
1. Buzzer akan berbunyi **"Tit" pendek 1 kali**.
2. Layar monitor kecil akan menyala dan menampilkan tulisan pembuka:
   ```
   SmartNaga v2
   Booting...
   ```
3. Dalam waktu 5–10 detik, layar akan berubah menampilkan jam dan status lampu. Ini tandanya alat sudah siap digunakan!

## BAGIAN 3: CARA MENGHUBUNGKAN ALAT KE WIFI / HOTSPOT HP

### 3.1 Kapan Anda Perlu Melakukan Pengaturan WiFi?

Anda hanya perlu melakukan langkah ini jika:
* Alat baru pertama kali dipasang di kebun.
* Anda mengganti kata sandi atau nama WiFi kebun / modem 4G.
* Anda ingin menyambungkan alat ke Hotspot HP pribadi.

Jika layar monitor di box panel menampilkan tulisan seperti ini:
```
== SETUP WIFI ==

1. Konek ke WiFi:
   SmartNaga-AP
2. Pass: smartnaga123
3. Buka 192.168.4.1
```
Artinya alat sedang menunggu Anda memasukkan nama dan kata sandi WiFi.

---

### 3.2 Langkah Mudah Sambung WiFi Lewat HP (Hanya 3 Menit)

Pegang smartphone Anda, berdiri di dekat box panel, lalu ikuti langkah mudah berikut:

```
Langkah 1:                Langkah 2:                Langkah 3:
Buka Menu Wi-Fi di HP     Ketik Password:           Otomatis Terbuka Halaman
Pilih "SmartNaga-AP"      smartnaga123              Pilih "Configure WiFi"
┌────────────────────┐    ┌────────────────────┐    ┌────────────────────┐
│ Wi-Fi              │    │ Masukkan Sandi:    │    │   SmartNaga WiFi   │
│ ✓ SmartNaga-AP     │    │ [smartnaga123    ] │    │ [Configure WiFi]   │
│   WiFi_Rumah       │    │                    │    │ [Info]             │
│   Modem_Kebun      │    │ [ Sambungkan ]     │    │ [Exit]             │
└────────────────────┘    └────────────────────┘    └────────────────────┘
```

1. **Buka Menu Pengaturan Wi-Fi di HP Anda.**
2. Cari dan klik nama jaringan: **`SmartNaga-AP`**.
3. Masukkan kata sandi: **`smartnaga123`** lalu klik Sambungkan.
4. Biasanya jendela peramban (browser) akan muncul secara otomatis di layar HP Anda.  
   *(Jika tidak muncul otomatis, buka Google Chrome di HP Anda, lalu ketik angka ini di kolom website: `192.168.4.1` lalu tekan Enter).*
5. Pada halaman yang muncul di layar HP, klik tombol paling atas: **Configure WiFi**.
6. HP akan menampilkan daftar WiFi di sekitar kebun Anda. **Klik nama WiFi kebun Anda** (atau nama Hotspot HP Anda).
7. Masukkan kata sandi WiFi kebun Anda pada kolom **Password**.
8. Klik tombol **Save** di bagian bawah.

Selesai! Alat SmartNaga akan menyimpan data tersebut dan menyambung ke internet secara otomatis.

---

### 3.3 Cara Memastikan Alat Sudah Tersambung ke Internet

Lihat baris kedua pada layar monitor kecil di box panel:

* Jika tertulis: **`Wifi: online 45ms`**  
  👉 **Bagus sekali!** Alat sudah terhubung ke internet dan siap dipantau lewat aplikasi di HP.
* Jika tertulis: **`Wifi: No Internet`**  
  👉 Alat terhubung ke modem/router, tetapi kuota internet habis atau sinyal seluler sedang hilang.
* Jika tertulis: **`Wifi: offline`**  
  👉 Alat belum menemukan sinyal WiFi. Pastikan modem 4G Anda menyala.

## BAGIAN 4: MEMBACA LAYAR MONITOR KECIL DI BOX PANEL

Anda tidak perlu selalu membuka HP untuk melihat kondisi kebun. Cukup lihat layar kecil di pintu box panel.

### 4.1 Arti Tampilan 7 Baris di Layar

```
┌──────────────────────────────────────┐
│               18:30:00               │ ◄── [Baris 1] Jam saat ini di kebun
│ Wifi: online 48ms                    │ ◄── [Baris 2] Status internet (online/offline)
│ Source: PLN                          │ ◄── [Baris 3] Sumber listrik (PLN atau UPS)
│ Blok A: 850W                         │ ◄── [Baris 4] Daya listrik Blok A yang terpakai
│ Status: 10/10 Normal                 │ ◄── [Baris 5] Kondisi kesehatan lampu Blok A
│ Blok B: 850W                         │ ◄── [Baris 6] Daya listrik Blok B yang terpakai
│ Status: 10/10 Normal                 │ ◄── [Baris 7] Kondisi kesehatan lampu Blok B
└──────────────────────────────────────┘
```

* **Baris 1 (Jam):** Jam penunjuk waktu kebun. Jam ini selalu tepat karena menyelaraskan otomatis dengan satelit internet dan baterai cadangan.
* **Baris 2 (WiFi):** Menunjukkan apakah koneksi internet lancar. Angka "ms" (milidetik) menunjukkan kecepatan sinyal; semakin kecil angkanya, semakin bagus.
* **Baris 3 (Source):**
  * `Source: PLN` = Listrik utama kebun menyala normal.
  * `Source: UPS` = Listrik PLN sedang mati! Sistem sedang menggunakan baterai cadangan.
* **Baris 4 & 6 (Daya Blok A & B):** Menunjukkan jumlah Watt listrik yang sedang disedot oleh lampu di blok tersebut.
* **Baris 5 & 7 (Status Lampu):** Keterangan apakah lampu menyala normal atau ada kerusakan.

---

### 4.2 Contoh Tampilan Layar Saat Kondisi Normal

Jika lampu sedang dinyalakan dan semua bohlam berfungsi baik:
```
Blok A: 900W
Status: 10/10 Normal
```
*Artinya:* Dari 10 lampu yang terpasang di Blok A, **semuanya menyala normal** dengan daya 900 Watt.

Jika lampu sedang dimatikan (siang hari):
```
Blok A: 0W
Status: Standby
```
*Artinya:* Lampu sedang padam/istirahat normal, tidak ada listrik yang bocor.

---

### 4.3 Contoh Tampilan Layar Saat Ada Lampu Rusak

Jika ada lampu yang putus atau mati tertiup angin:
```
Blok A: 720W
Status: 8/10 Normal
```
*Artinya:* Seharusnya ada 10 lampu yang menyala, tetapi alat mendeteksi hanya **8 lampu yang hidup** (ada **2 lampu yang padam/putus**). Anda bisa langsung memeriksa tiang kebun untuk mengganti bohlam yang mati.

## BAGIAN 6: PANDUAN MENGGUNAKAN APLIKASI DI SMARTPHONE

Semua kontrol kebun ada di genggaman Anda melalui aplikasi **SmartNaga** di HP Android atau iPhone Anda.

### 6.1 Membuka Aplikasi & Melihat Kondisi Kebun

1. Buka aplikasi **SmartNaga** di smartphone Anda.
2. Di halaman utama (**Dashboard**), Anda akan melihat:
   * Status perangkat: **Online** (hijau) atau **Offline** (abu-abu).
   * Kotak status **Blok A** dan **Blok B**.
   * Tegangan listrik kebun (misal: `220 Volt`).
   * Konsumsi daya saat ini (misal: `1.800 Watt`).
   * Total pemakaian listrik malam ini (dalam satuan `kWh`).

---

### 6.2 Menyalakan dan Mematikan Lampu Secara Manual

Jika sewaktu-waktu Anda ingin menyalakan lampu kebun di luar jadwal (misalnya untuk menyemprot pupuk atau inspeksi malam):

1. Pada kartu **Lampu Blok A** atau **Lampu Blok B**, cukup geser tombol saklar menjadi **ON**.
2. Dalam hitungan 1 detik, alat di kebun akan berbunyi *"Tit"* dan kontaktor akan berbunyi *"Cklek"*, lalu lampu kebun langsung menyala terang.
3. Untuk mematikan kembali, geser tombol saklar menjadi **OFF**.

---

### 6.3 Mengatur Jadwal Lampu Otomatis (Timer Malam Hari)

Anda tidak perlu repot menyalakan lampu setiap sore dan mematikannya tengah malam. Gunakan fitur **Jadwal Otomatis (Scheduler)**:

```
               PENGATURAN JADWAL LAMPU
┌────────────────────────────────────────────────────────┐
│  Penyinaran Rutin Malam Hari                           │
│  Jam Nyala : [ 18 : 00 ] Sore                          │
│  Jam Padam : [ 22 : 00 ] Malam                         │
│  Hari Aktif: [ Senin ] [ Selasa ] [ Rabu ] [ Kamis ]   │
│              [ Jumat ] [ Sabtu  ] [ Minggu ]           │
│                                                        │
│  [  SIMPAN JADWAL  ]                                   │
└────────────────────────────────────────────────────────┘
```

1. Buka menu **Jadwal (Schedule)** di aplikasi.
2. Tentukan **Jam Nyala** (misal pukul `18:00`).
3. Tentukan **Jam Padam** (misal pukul `22:00` atau `00:00`).
4. Centang hari-hari penyinaran yang diinginkan.
5. Klik **Simpan Jadwal**.  
*Kini lampu kebun akan menyala dan mati sendiri tepat waktu setiap malam, meskipun HP Anda mati atau kehabisan baterai!*

---

### 6.4 Mengisi Jumlah Lampu Kebun (PENTING untuk Deteksi Kerusakan)

Agar alat bisa menghitung berapa bohlam yang putus secara tepat, Anda wajib memasukkan data lampu kebun Anda:

1. Buka menu **Pengaturan Kebun** → pilih **Konfigurasi Lampu**.
2. Masukkan data lampu untuk masing-masing blok:
   * **Jumlah Lampu:** Berapa buah bohlam yang terpasang di tiang kebun Anda (misal: `100` buah).
   * **Daya Total Normal (Watt):** Total daya semua bohlam saat menyala normal (misal: 100 buah bohlam 9 Watt = `900` Watt).
   * **Toleransi (%):** Biarkan pada angka rekomendasi `15%`.
3. Klik tombol **Simpan Konfigurasi**.

> [!TIP]
> **Kapan Data Ini Harus Diubah?**  
> Ubah data ini jika Anda menambah tiang buah naga baru, memasang bohlam tambahan, atau mengganti watt bohlam dengan ukuran yang berbeda.

## BAGIAN 7: CARA MENGATASI GANGGUAN LAMPU (PEMECAHAN MASALAH)

Ketika terjadi sesuatu yang tidak biasa di kebun, layar monitor dan notifikasi HP akan menampilkan pesan khusus. Berikut panduan praktis untuk mengatasinya:

### 7.1 Status "Listrik Padam"
* **Apa yang terjadi:** Lampu seharusnya menyala, tetapi aliran listrik PLN dari tiang jalan padam total.
* **Tanda di box:** Buzzer berbunyi panjang 2 detik, tulisan `Source: UPS` dan `Status: Listrik Padam`.
* **Tindakan Anda:** 
  1. Periksa apakah tetangga sekitar kebun juga mengalami mati lampu PLN.
  2. Anda tidak perlu mematikan alat secara manual; begitu listrik PLN kembali mengalir, alat akan otomatis menyalakan lampu kembali sesuai jadwal.

---

### 7.2 Status "Lampu Padam" (Semua Lampu Mati Padahal Listrik Ada)
* **Apa yang terjadi:** Saklar lampu dalam posisi ON dan listrik PLN hidup, tetapi tidak ada daya sama sekali (0 Watt).
* **Penyebab:** Tuas MCB beban di dalam panel turun (trip), atau ada kabel fasa utama menuju tiang kebun yang terputus (misal tertimpa dahan pohon).
* **Tindakan Anda:**
  1. Buka box panel, periksa tuas **MCB Beban (10A)**. Jika turun ke bawah, naikkan kembali ke atas.
  2. Jika MCB langsung turun kembali dengan keras, **JANGAN DIPAKSAKAN!** Ada korsleting kabel di tiang kebun. Periksa kabel di deretan pohon buah naga sebelum menaikkan MCB kembali.

---

### 7.3 Status "Lampu Rusak" (Ada Sebagian Bohlam yang Mati)
* **Apa yang terjadi:** Lampu menyala, tetapi dayanya kurang dari biasanya karena ada beberapa bohlam yang mati.
* **Tanda di layar:** Tertulis perbandingan, misalnya `Status: 18/20 Normal`.
* **Tindakan Anda:**
  1. Angka `18/20` artinya ada **2 bohlam yang putus**.
  2. Bawa bohlam cadangan, jalan menyusuri deretan tiang kebun, dan cari 2 bohlam yang tidak berpijar.
  3. Ganti bohlam yang putus tersebut. Begitu bohlam baru terpasang, angka di layar akan otomatis kembali menjadi `20/20 Normal`.

---

### 7.4 Status "Tegangan Rendah" atau "Tegangan Tinggi"
* **Apa yang terjadi:** Voltase listrik dari gardu PLN sedang tidak stabil (turun di bawah 190 Volt atau melonjak di atas 245 Volt).
* **Tindakan Anda:** 
  * Tegangan yang terlalu rendah atau terlalu tinggi berbahaya bagi usia lampu LED Anda. Jika kondisi ini terjadi terus-menerus, hubungi kantor PLN terdekat untuk perbaikan trafo distribusi di wilayah perkebunan Anda.

---

### 7.5 Status "Relay Bocor"
* **Apa yang terjadi:** Anda sudah mematikan lampu di aplikasi HP (posisi OFF), tetapi lampu di tiang kebun masih tetap menyala atau ada arus listrik yang bocor.
* **Penyebab:** Kontak mekanis di dalam kontaktor magnetik lengket atau terjadi rembesan arus.
* **Tindakan Anda:**
  1. Turunkan tuas MCB Lampu Beban untuk mematikan lampu secara paksa agar listrik tidak terbuang sia-sia.
  2. Hubungi teknisi untuk memeriksa kontaktor atau modul relay di dalam panel.

## BAGIAN 8: KESELAMATAN & PERAWATAN ALAT

### 8.1 Aturan Keselamatan Listrik di Kebun

1. **Selalu Matikan MCB Sebelum Menyentuh Kabel:** Jangan pernah menyentuh kabel telanjang, terminal baut, atau mengganti kontaktor saat tuas MCB masih menyala.
2. **Keringkan Tangan & Pakai Sandal/Sepatu Karet:** Tanah perkebunan buah naga cenderung basah dan lembap. Selalu kenakan alas kaki berbahan karet kering saat membuka box panel.
3. **Pintu Box Harus Selalu Terkunci Rapat:** Setelah memeriksa alat, pastikan pintu box panel tertutup rapat dan kuncinya terpasang agar air hujan lebat dan serangga malam tidak masuk ke rangkaian elektronik.

---

### 8.2 Perawatan Rutin Bulanan

* **Bulan 1 (Pembersihan Box):** Periksa apakah ada sarang semut atau serangga di ventilasi box. Bersihkan debu luar dengan kain kering.
* **Bulan 3 (Pemeriksaan Baterai UPS):** Matikan MCB PLN utama selama 5 menit di siang hari. Pastikan layar kecil dan modem internet tetap hidup lancar menggunakan tenaga baterai cadangan.
* **Bulan 6 (Pemeriksaan Baut Kabel):** Getaran kontaktor secara berkala bisa membuat baut kabel sedikit kendor. Minta teknisi mengencangkan kembali baut-baut kabel listrik di terminal blok.

## BAGIAN 9: PERTANYAAN YANG SERING DITANYAKAN (FAQ)

**T: Jika internet atau sinyal modem kebun saya mati total, apakah lampu malam tetap menyala otomatis?**  
**J:** **YA, TETAP MENYALA!** Alat SmartNaga memiliki chip jam mandiri (*RTC*) yang menyimpan jadwal di dalam memorinya. Meskipun sinyal hilang berhari-hari, lampu kebun akan tetap menyala dan padam tepat waktu sesuai jadwal yang sudah tersimpan.

**T: Apakah alat ini aman jika terkena hujan lebat dan petir?**  
**J:** Box panel menggunakan standar *outdoor IP65* yang kedap semprotan air hujan. Namun untuk perlindungan sambaran petir di area terbuka kebun, sangat dianjurkan tiang utama panel dilengkapi kawat arde (*grounding*) yang tertancap ke tanah basah sedalam minimal 1,5 meter.

**T: Saya baru saja membeli kuota baru / mengganti modem WiFi kebun, apa yang harus saya lakukan?**  
**J:** Cukup ikuti panduan di **BAGIAN 3**. Sambungkan HP ke `SmartNaga-AP`, buka halaman `192.168.4.1`, lalu pilih nama modem baru dan masukkan kata sandinya.

**T: Bisakah aplikasi SmartNaga dibuka oleh lebih dari satu orang di keluarga saya?**  
**J:** Bisa. Aplikasi dapat dipasang di beberapa HP (misalnya HP pemilik dan HP penjaga kebun) dengan masuk menggunakan akun email kebun yang sama.
